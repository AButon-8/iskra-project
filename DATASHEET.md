## Процесс сбора | Collection Process

| Параметр | Значение |
|---|---|
| **Принципы формирования** | Бесспорная атрибуция, жанровая сопоставимость, временные рамки (с допустимыми исключениями), сопоставимый объем текстов. Подробное описание см. Протокол сбора |
| **Типы источников** | Печатные издания; электронные публикации; оцифрованные копии документов |
| **Ключевые собрания** | Отдел редкой книги Центра социально-политической истории (ОРК ЦСПИ); цифровые собрания сочинений; универсальные электронные библиотеки; специализированные исторические ресурсы |
| **Источники (по каждому тексту)** | См. в соответствующей строке колонки `SourceName` таблицы `IAC_Metadata.csv` в репозитории проекта |
| **Способы получения текстов** | 1) извлечение из существующих электронных публикаций; 2) оптическое распознавание (OCR) цифровых копий; 3) ручной набор текста |
| **Инструмент OCR** | Tesseract OCR; для отдельных изображений — Live Text (macOS) |
| **Дообучение модели** | Fine-tuning стандартной модели `rus` на 10 000+ парах «изображение — текст»; создана специализированная модель `orus` (old Russian), CER ~2% |
| **Репозиторий модели** | https://github.com/AButon-8/iskra_ocr |
| **Протокол сбора** | Полное описание процедур формирования и разметки корпуса зафиксировано в протоколе. На момент публикации версии 1.0 протокол не размещён в репозитории; планируется его публикация в разделе docs/ репозитория |

## Предобработка / очистка / разметка | Preprocessing / Cleaning / Labeling

| Параметр | Значение |
|---|---|
| **Этапы нормализации** | 1) автоматическое преобразование дореформенной орфографии в современную (модуль `Prereform2modern`); 2) очистка текста регулярными выражениями (артефакты OCR, элементы верстки, графические аномалии); 3) ручная проверка и валидация |
| **Разметка** | Атрибуты в имени файла: `_I`, `_orus`, `_NQ`; поле `textValidation` в таблице метаданных фиксирует факт ручной сверки с оригиналом |
| **Контроль качества** | Ручная сверка с оригиналом; валидация нормализации; удаление технических элементов и длинных цитат; аудит корпуса (объем, структура, контаминация) |
| **Таблица метаданных** | `IAC_Metadata.csv` — включает поля: `authorFull`, `authorID`, `authorGender`, `titleFull`, `titleID`, `publYear / written`, `publDate`, `publishedBy`, `sizeToken / Word`, `sizeDigit`, `size, kb`, `textSource`, `textValidation`, `comments` |
| **Связь текстов и метаданных** | Через уникальный идентификатор текста `titleID` |

## Использование | Uses

| Параметр | Значение |
|---|---|
| **Область применения** | Атрибуция текстов, стилометрический анализ, корпусный анализ, формирование обучающих наборов данных для методов машинного обучения |
| **Репозиторий** | https://github.com/AButon-8/iskra-project/tree/main/corpus |
| **Ограничения по составу** | Только бесспорно атрибутированные тексты восьми авторов; жанровое ограничение — публицистика; значительная часть текстов авторов «Искры» осталась за пределами коллекции из-за труднодоступности источников |
| **Ограничения и риски** | Дисбаланс авторов, неполнота корпуса, жанровая ограниченность, ошибки OCR и нормализации, контаминация корпуса |
| **Рекомендации по использованию** | Учитывать дисбаланс объемов при построении моделей; dubia-тексты использовать только для верификации, не для обучения; при интерпретации результатов учитывать исторический контекст публикаций |
