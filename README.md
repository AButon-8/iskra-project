# Iskra-project

Репозиторий исследования корпуса русской революционной нелегальной печати начала XX века (на материале газеты «Искра», 1900–1905 гг.).

Проект ведётся в рамках учебной и исследовательской работы и будет постепенно расширяться.

---

## Структура репозитория

CORPUS      # исходные тексты в формате .txt
- dubia/
- krupskaya/
- lenin/
- martov/
- etc.../


DATA        # табличные данные


FEATURES    # признаки (матрицы)
- mfw_100/300/500/1000_norm 
# mfw с нормализацией (частота на 1000 слов)
- char_3/4gram_norm 
# char n-gram: min_occurrence = 5, max_features = 500, нормализация на 1000 знаков

- data/
- notebooks/
